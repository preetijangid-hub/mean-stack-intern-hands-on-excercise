# Day 25 - Git, GitHub & Deployment

##  Overview

Day 25 focuses on Git, GitHub workflow, environment variables, secrets management, and deployment of the backend API using Render with MongoDB Atlas.

##  Objectives

- Understand Git basics
- Create and work with feature branches
- Push changes to GitHub
- Create a Pull Request
- Understand `.gitignore`
- Protect environment variables and secrets
- Deploy Express API on Render
- Connect deployed API with MongoDB Atlas
- Verify live API endpoints

##  Technologies Used

- Git
- GitHub
- Node.js
- Express.js
- MongoDB Atlas
- Render
- REST API
- Environment Variables
