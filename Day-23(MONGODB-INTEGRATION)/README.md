# Day 22 - MongoDB Integration

## Topic

Express + MongoDB Integration

## Objective

In this hands-on exercise, an Express.js API is connected with MongoDB Atlas using Mongoose.

## Topics Covered

- MongoDB Atlas connection
- Environment variables
- dotenv configuration
- Mongoose
- MongoDB schema and model
- Express routing
- CRUD operations
- async/await
- Error handling
- Not-found handling
- MongoDB persistence
