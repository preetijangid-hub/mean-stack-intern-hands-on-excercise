# Day 01 - JavaScript Basics

## Objective

The objective of Day 01 was to build a strong foundation in JavaScript by learning core programming concepts and implementing simple problem-solving exercises.

---

## Topics Covered

- Variables (`let`, `const`, `var`)
- Data Types
- Operators
- Conditional Statements
- Loops
- FizzBuzz Program
- Temperature Converter
