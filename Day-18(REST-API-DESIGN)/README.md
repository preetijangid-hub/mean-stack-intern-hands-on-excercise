# Day 18 - REST API Design (CRUD)

## Overview

This project demonstrates REST API design using Node.js and Express.js.

The API manages an in-memory collection of tasks and implements the main CRUD operations:

- GET
- POST
- PUT
- DELETE

It also demonstrates REST API concepts such as:

- Resources and nouns
- HTTP methods
- HTTP status codes
- Route parameters
- Query parameters
- REST conventions
- CRUD operations
- Request body handling
- In-memory data storage

---

## Technologies Used

- Node.js
- Express.js
- JavaScript
- REST API
- HTTP
