# CLI Note Tool

A simple command-line note management application built with Node.js.

## Concepts Used

- Node.js
- fs/promises
- async/await
- JSON file handling
- path module
- process.argv
- Error handling
- npm scripts

## Features

- Add notes
- List notes
- Delete notes
- Store notes inside a JSON file
- Handle invalid commands and errors

## Run

node app.js

## Add

node app.js add "Learn Node.js"

## List

node app.js list

## Delete

node app.js delete 1
