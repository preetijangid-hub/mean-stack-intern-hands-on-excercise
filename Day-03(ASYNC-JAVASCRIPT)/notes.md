# Day 03 Notes

## Callback

A callback is a function passed into another function.

## Promise

Promise represents the eventual completion or failure of an asynchronous operation.

States:

- Pending
- Fulfilled
- Rejected

## Async Await

Cleaner syntax for working with promises.

## Try Catch

Used to handle errors.

## Fetch API

Used to request data from APIs.

## Promise.all()

Runs multiple promises simultaneously.
