# TaskFlow Project Build

This folder contains the daily development of **TaskFlow**, a Task Management application built during the Mean Stack Internship.

The project is developed incrementally by implementing one feature each day.

---

# Project Overview

TaskFlow is a task management application that allows users to:

- Manage tasks
- Update task status
- Organize work efficiently
- Navigate between pages
- Validate forms
- Fetch data from APIs
- Apply routing and guards
- Build responsive Angular UI
